# 🗄️ 文档归档库 (Archive)

本目录专门用于存放 **已废弃、已过时、或已被新版本完全取代的历史文档与探索草稿**，仅作历史溯源与技术决策追溯备查，不参与当前主线开发。

---

## 📂 归档分类准则

| 归档类型 | 适用内容 | 示例 |
| :--- | :--- | :--- |
| **废弃技术方案** | 经实验证伪或被更高优方案取代的原型草稿 | Task 01 早期 CLAHE 图像增强方案草稿 |
| **历史迭代归档** | 当迭代演进到更高级别时，已结项的历史迭代记录 | 早期实验草稿与历史基线记录 |
| **过时平台说明** | 已经不再使用的旧平台特定运行记录与旧 Notebook | 历史平台手工迁移草稿 |

---

## 📌 归档文档维护规范

1. 归档文件标题顶部需显式标注 `> [!NOTE]` 状态标记：
   ```markdown
   > [!NOTE]
   > 本文档为历史归档文件（归档日期：YYYY-MM-DD），内容已被最新方案取代，仅供溯源备查。
   ```
2. 保持文件内容原貌，不做破坏性删除；
3. 任何当前处于活跃（Active）状态的技术方案请存放于 `docs/iterations/` 或 `docs/research/`。
