## 三、 数据模态与格式技术规格

每个样本包含 **4 个模态**（三视觉 + 一文本）：

```text
[Sample]
  ├── 1. 可见光 (Visible RGB):   三通道 uint8 [0, 255]，原图无损尺寸
  ├── 2. 热红外 (Infrared):      三通道 uint8 [0, 255]，3 个单通道热辐射灰度堆叠，数值越高越亮/温度越高
  ├── 3. 深度图 (Depth):         单通道 uint16 [0, 65535]，单位毫米 (mm)，有效感知 300~20000mm，0 为无效
  └── 4. 文本指令 (Query):       单句英文描述，指向画面中唯一的物理目标
```

### 目标标注 (Ground Truth)
* 格式为 `[x1, y1, x2, y2]`，必须严格归一化至 `[0.0, 1.0]` 区间。
* $0 \le x_1 < x_2 \le 1.0$，$0 \le y_1 < y_2 \le 1.0$。
* 任何出现反向坐标（$x_1 \ge x_2$ 或 $y_1 \ge y_2$）、越界、含 `NaN`、空框等情况直接判定为**无效预测**。

## 四、 评价指标与算分规则

* **核心评价指标**：**`ACC@0.5`**
* **判定命中准则**：预测框 $A$ 与真实标注框 $B$ 的交并比 $\text{IoU} \ge 0.5$ 计为正确（Hit）。
  $$\text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|}$$
  $$\text{ACC@0.5} = \frac{\text{IoU} \ge 0.5 \text{ 的有效样本数}}{\text{测试集全部查询样本总数}}$$
* **基线限制**：提交结果若低于官方发布的基线成绩，赛事方有权认定为无效成绩。

## 五、 赛题严格约束与违规红线（合规审查清单）

> [!IMPORTANT]
> 必须严格遵守以下四条核心红线，否则将被直接取消参赛资格与奖项：

1. **算法推理限制（禁止商业 API 在线推理）**：
   * ❌ **严禁调用商业闭源大模型的在线推理 API**（如 GPT-4o、Claude 3.5 Sonnet 等远程调用接口生成测试集结果）。
   * ✅ **仅允许使用开源大模型（如 Qwen-VL、InternVL、LLaMA-Grounding）或自研大模型**进行本地/云端部署与自主推理。
2. **禁止手工标注测试集**：
   * ❌ 严禁任何形式的人工干预、测试集人工标注或打标修正，所有坐标必须由模型自主前向推理输出。
3. **数据集使用规范**：
   * ✅ **允许使用外部公开数据集**（如 COCO、RefCOCO、开源跟踪数据集等）用于离线预训练/微调（需在半决赛技术报告中注明来源与处理流程）。
   * ❌ **严禁将测试集数据用于任何训练环节**（必须进行严格的 SHA-256 数据去重防穿越）。
4. **数据保密协议**：
   * ❌ 官方测试集禁止任何形式的外泄、上传至公共代码仓库（如未私有化的公开 GitHub）、开源或商用。

## 六、 提交数据格式标准 (Submission Protocol)

提交文件必须为 `submission.zip`，解压后必须仅包含唯一的 `result.json`，且**除 `bbox` 字段外不得增删修改任何原有键值**。

```json
{
  "000002_001": {
    "visible": "Images/visible/000002.png",
    "infrared": "Images/infrared/000002.png",
    "depth": "Images/depth/000002.png",
    "query": "Red promotional sign with food imagery",
    "bbox": [0.124567, 0.345678, 0.567890, 0.789012]
  }
}
```
