# 🔬 赛题规则与核心技术调研分析

---

## 一、 赛题与数据集规格

* **赛题名称**：第八届全球校园人工智能算法精英大赛 · 基于大模型的多模态视觉理解与推理
* **核心任务**：输入时间同步、空间对齐的可见光（RGB）、热红外（Infrared）与深度图（Depth），定位英文 Query 所指示的目标归一化边界框 `[x1, y1, x2, y2]`。
* **官方评价指标**：`ACC@0.5`（预测框与真值框的 $\text{IoU} \ge 0.5$ 计为命中）。

### 1. 四模态数据特征
1. **可见光 (Visible RGB)**：三通道 uint8 `[0, 255]`，1080p 原图无损尺寸；
2. **热红外 (Infrared)**：三通道 uint8 `[0, 255]`（单通道热辐射灰度三副本堆叠），高温/发热物体亮度显著；
3. **深度图 (Depth)**：单通道 uint16 `[0, 65535]`，单位毫米 (mm)，有效测距 300~20,000mm（0 为无效/反射缺失）；
4. **文本指令 (Query)**：英文单句描述，指向唯一目标。

### 2. 统计学关键发现（数据命门）
* **超小目标占绝对主导**：**58.4% 的目标边界框面积小于图像的 1.5%**（中位数目标仅 $25 \times 30$ 像素），因此模型必须保持 1080p 全分辨率无损输入（禁止暴力下采样压缩！）；
* **深度测量有效区间**：99.7% 的深度像素集中在 0.3m ~ 20.0m，采用固定尺度 8-bit JET 色彩编码映射具有全局一致的物理距离语义；
* **测试集防泄漏查重**：通过 SHA-256 字节级全哈希比对，严格剔除 Train/Val 中与 Test 同源的图像帧。

## 二、 模型选型与多模态定位基准

| 模型系列 | 参数量 | 多模态输入机制 | 坐标预测能力 | 预期基线 (ACC@0.5) | 评语 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **Qwen3-VL-8B-Instruct** | **8.8B** | **原生 2D-RoPE 连续动态网格 (3072 Patches)** | **0~1000 整数坐标 Token** | **0.7439 $\rightarrow$ 0.77+** | **👑 当前主力模型，长宽比自适应、精度极高** |
| **InternVL-3.5-8B** | 8.0B | $448 \times 448$ 瓷砖动态切片 (Tile-based) | `[ymin, xmin, ymax, xmax]` 整数 | 0.7100 ~ 0.7400 | 备选大模型，需注意 Y/X 坐标轴颠倒防坑 |
| **Grounding DINO** | 0.2B | Swin-T / Swin-B 专用目标检测器 | 连续浮点坐标回归 | 0.5800 ~ 0.6500 | 判别式小模型，边缘敏感，适合作为多模型融合特征补充 |

## 三、 官方合规与提交要求

1. **禁止商业闭源 API 在线推理**：严禁调用 GPT-4o / Claude 等远程 API 生成测试集坐标，必须使用开源或自研模型自主部署推理；
2. **严禁人工干预测试集**：所有测试集预测必须由模型前向自动生成；
3. **提交格式规范**：提交包必须为 `submission.zip`，解压后仅包含唯一的 `result.json`，除 `bbox` 字段外不得修改任何原有键值。
