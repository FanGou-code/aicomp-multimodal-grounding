图号快速跳转规则

在顶部「输入图号/编号」输入框中输入图片文件名（如 000002、000002_visible）或 Item ID 前缀（如 000002_001），回车即可直接定位到该图的第一条 Query。

输入 #500 可直接跳到第 500 条（按序数）；纯数字若未匹配到 id/图号，也会自动按序数处理。上方的滑杆支持拖动快速翻页：拖动时预览序号，松开即跳转。
