## 二、 核心赛题深度解析：基于大模型的多模态视觉理解与推理

### 1. 赛题背景与实际应用场景
- **核心定义**：赛题围绕**视觉定位（Visual Grounding）**问题展开。传统目标检测仅识别物体类别和位置，而真实智能体需理解人类自然语言描述，并在复杂、异构的场景中精准定位目标 [2]。
- **多模态融合的必要性**：在真实场景中，单一视觉（如可见光）容易受到弱光、遮挡或相似物体干扰 [2]。因此，赛题引入了**可见光（RGB）**、**热红外（Infrared）**和**深度（Depth）**三种视觉模态，考查跨模态语义对齐与推理 [2]。
- **典型应用场景（智能安防应急处置）**：
  - **输入指令**：监控后台接到“园区西北角围墙处，蹲在草丛中、身高约1.7米的可疑人员”这一文本模态输入 [3]。
  - **多模态协同**：
    - **可见光 RGB**：捕捉目标衣着纹理、草丛及围墙细节 [3]；
    - **热红外图像**：在夜间低光或遮挡环境下突显目标热源轮廓，区分活体与静物 [3, 4]；
    - **深度传感器**：获取目标的三维尺寸和到相机的空间距离，从而验证是否匹配文本中的“身高”和“位置”信息 [3, 4]。
  - **大模型核心角色**：实现文本语义与多模态视觉特征的精准对齐和关联推理，最终精准锁定目标 [4]。

### 2. 赛题任务及输入输出规范
- **任务描述**：给定目标的英文文本语义描述（Query），对可见光 RGB 图像、红外图像、深度图像三种视觉模态数据进行协同分析，从而精准定位目标在可见光图像中的具体位置 [5]。
- **算法输入** [6]：
  1. 可见光图像（RGB）
  2. 深度图（Depth）
  3. 热红外图像（Infrared）
  4. 目标语义描述查询文本（Query，描述特定目标的英文句子）
- **算法输出** [6]：
  - 目标在可见光图像中的边界框（Bounding Box, BBox），格式为 `[x1, y1, x2, y2]`。
  - **归一化处理**：所有输出坐标必须除以图像对应边长（宽度对应 x轴，高度对应 y轴），归一化至 `[0, 1]` 范围。其中 `(x1, y1)` 为左上角相对坐标，`(x2, y2)` 为右下角相对坐标 [5, 6]。

### 3. 数据集与数据格式说明
- **数据来源**：自行采集的真实场景数据（涵盖街道、校园、动物园、室内、公园等，均已人工对齐）[6, 8]。查询文本由人工标注，确保每条文本指向图像中**唯一**的目标 [6]。
- **数据组成**：包含初赛、复赛、半决赛评测集 [6]。
- **具体格式细节** [7]：
  - **可见光图像**：三通道 8位无符号整型，像素取值 `[0, 255]` [7]。
  - **热红外图像**：三通道 8位无符号整型（本质为 3 个单通道热辐射灰度图堆叠，无彩色语义），取值 `[0, 255]`，亮度越高代表目标温度越高 [7]。
  - **深度图像**：单通道 16位无符号整型，单位为**毫米**（mm）。深度相机感知范围约 30cm 到 20m（取值 `[0, 19999]`），0代表无效深度，值越大代表越远 [7]。
  - **关联文件**：JSON 结构化存储。以唯一的查询文本 ID（Query ID）为索引，对应多模态图像的相对路径、查询文本以及归一化的 bbox 真实标注 [7]。

## 三、 算法设计与约束条件

### 1. 算法技术路线要求
- **优先大模型路线**：鼓励基于大模型技术体系，采用并优化适配多模态场景的深度学习算法 [8]。

- **创新性方向**：建议针对通用大模型定位精度不足或跨模态语义偏差等问题，设计专属的视觉编码器、模态交互层或后处理模块，强化对多模态数据的深度理解 [9]。

## 四、 成绩评价与性能指标

### 1. 评估指标（ACC@0.5）
- **交并比 IoU**：用于判断定位是否正确的指标。
  $$IoU(A, B) = \frac{|A \cap B|}{|A \cup B|}$$
  其中 A 为预测边界框（BBox），B 为真实边界框 [9]。
- **定位正确判定**：预测框与真实框的 $IoU \ge 0.5$ 时判定为有效/正确 [9]。
- **准确率计算公式**：
  $$ACC@0.5 = \frac{IoU \ge 0.5 \text{ 的有效查询样本数量}}{\text{测试集全部查询样本总数量}}$$ [9]

### 2. 边界框异常判定规范
如果在预测结果中出现以下异常边界框，评测程序将直接判定为**无效预测**（即该样本 IoU 计为 0）[12]：
- **反向坐标**（如 $x1 \ge x2$ 或 $y1 \ge y2$）[12]
- **坐标越界**（超出 `[0, 1]` 范围）[12]
- **数值异常**（包含 NaN 字符）[12]
- **无效空框** [12]

## 六、 推荐解题技术路径

1. **数据预处理**：
   - **图像模态**：RGB 图像执行尺寸标准化和归一化；红外图像采用降噪和对比度增强（抑制噪声）；深度图像需要剔除无效离群值（如处理 0 像素），确保三个视觉模态在空间对齐的前提下发挥优势 [13]。
   - **文本模态**：进行 Token 化、文本标准化，并依据 Query ID 将文本与对应的三模态图像正确关联 [13]。
2. **特征提取**：
   - 采用不同的预训练模型（如 **CLIP** 等经典视觉表征网络）分别对可见光、红外与深度图像进行特征编码，提取外观纹理、热辐射及空间三维深度结构信息 [13]。
   - 引入多模态大模型（如 **LLaMA-Grounding、Qwen-VL、InternVL** 等）进行文本的深层语义理解，精确解析其描述的目标属性、空间关系及约束条件 [13, 14]。
   - 搭建跨模态特征映射层，将视觉特征与文本语义特征对齐到统一的特征空间 [14]。
3. **模型微调与适配**：
   - 搭建以开源大模型为核心的多模态架构，设计跨模态注意力或加权融合等融合机制 [14]。
   - 利用轻量化适配调优（如 **LoRA**）进行微调。推荐选用与 IoU 相关的 Loss 函数（如 GIoU Loss）来专门优化边界框回归逻辑 [14]。
4. **推理预测与结果集成**：
   - 模型推理得到坐标后，严格进行格式和边界约束校验，确保其归一化在 `[0, 1]` 之间且不含异常框 [14]。
   - 可采用多模型集成推理（例如不同视觉骨干或不同大模型基座的预测边界框进行加权平均），以显著提升定位准确度与鲁棒性 [14]。
